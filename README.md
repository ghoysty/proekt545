## Описание программы
*"Book Tracker (Трекер прочитанных книг) — это консольное приложение для управления списком прочитанных книг с возможностью фильтрации. Позволяет
добавлять данные в таблицу или список."*

- Библиотеки: `pip install matplotlib requests`
